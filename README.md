# Библиотека: выдача книг

Сервис библиотекаря: выдаёт экземпляры читателям, принимает возвраты, считает
просрочку и штраф, показывает сводку по фонду. Учебный сервис курсовой работы
по дисциплине «Оптимизация клиент-серверных приложений», вариант 1,
префикс `georgii_valiaikin`.

## Требования

- Docker 28 с Docker Compose v2 (проверено на Docker Desktop 28.5.1, WSL2 Ubuntu);
- больше ничего ставить не нужно: Python 3.12, FastAPI 0.118, psycopg 3.2 и
  PostgreSQL 16 работают в контейнерах.

## Установка и запуск

    git clone https://github.com/GeorgyV11/georgii_valiaikin-library.git
    cd georgii_valiaikin-library
    cp .env.example .env
    docker compose up -d --build
    docker compose exec api python -m app.seed small

`app.seed` создаёт схему `georgii_valiaikin` заново (таблицы, учётную запись)
и наполняет её. Наполнения два:

| Команда                                       | Читатели | Книги  | Экземпляры | Выдачи  |
|-----------------------------------------------|---------:|-------:|-----------:|--------:|
| `docker compose exec api python -m app.seed small` |       50 |    100 |        200 |     300 |
| `docker compose exec api python -m app.seed work`  |    3 000 | 10 000 |     30 000 | 100 000 |

Наполнение воспроизводимо: фиксированное зерно генератора и фиксированная
опорная дата, повторный запуск даёт те же строки.

## Переменные окружения

| Переменная    | Назначение                               | Пример     |
|---------------|------------------------------------------|------------|
| DB_PASSWORD   | пароль пользователя library в PostgreSQL | changeme   |
| SECRET_KEY    | ключ подписи куки сессии                 | changeme   |
| APP_PORT      | порт сервиса на машине                   | 8080       |
| DB_PORT       | порт PostgreSQL на машине                | 25432      |
| DB_POOL_SIZE  | размер пула соединений к базе            | 10         |

База данных и схема называются `georgii_valiaikin`, проект Compose — тоже.

## Проверка работоспособности

Интерфейс открывается по адресу http://localhost:8080, учётная запись для
проверки — `librarian` / `library`. После входа виден список выдач с фильтром
по статусу и читателю; карточка выдачи открывается по номеру, сводка — по
ссылке «Сводка», выдача — «Выдать книгу».

Каждый ответ сервиса несёт заголовки `X-Response-Time-ms` (время обработки),
`X-DB-Time-ms` (суммарное время запросов к базе) и `X-DB-Queries` (число
запросов к базе) — по ним время раскладывается между кодом и базой.

## Тесты

    docker compose exec api pytest

Тесты правил (`tests/test_rules.py`) работают без базы; тесты операций
(`tests/test_api.py`) поднимают отдельную схему `georgii_valiaikin_test` с
малым наполнением и рабочих данных не трогают.

## Замеры

    docker compose exec api python tools/measure.py --label work

Прогрев и 20 повторов на каждую операцию контракта под учётной записью
`librarian`; таблица p50 / p95 / максимум, время в базе и число запросов.
Результат сохраняется в `results/<label>.json`. Замер выдачи и возврата
добавляет в базу 43 выдачи.

## Программный интерфейс

Все операции, кроме входа, требуют сессии (кука `library_session`), без неё — 401.
Даты — в формате `YYYY-MM-DD`.

| Метод и путь                  | Параметры                                                    | Ответ                                                                 | Ошибки        |
|-------------------------------|--------------------------------------------------------------|-----------------------------------------------------------------------|---------------|
| POST /api/login               | тело: login, password                                        | 200 {id, login, name} и кука сессии                                   | 401, 422      |
| POST /api/logout              | —                                                            | 204                                                                   | —             |
| GET /api/loans                | page ≥ 1, size 1–100, status = all/active/overdue/returned, reader (часть ФИО) | 200 {items: [выдача], total, page, size}                | 401, 422      |
| GET /api/loans/{id}           | —                                                            | 200 выдача + reader, copy, book, overdue_days, fine                   | 401, 404, 422 |
| POST /api/loans               | тело: reader_id, copy_id                                     | 201 созданная выдача (срок — 14 дней)                                  | 401, 404, 409, 422 |
| POST /api/loans/{id}/return   | тело: returned_on (необязательно, по умолчанию сегодня)      | 200 закрытая выдача с overdue_days и fine                             | 401, 404, 409, 422 |
| GET /api/readers/{id}         | page ≥ 1, size 1–100 (история выдач)                         | 200 читатель + loans, loans_total, on_hand, has_overdue               | 401, 404, 422 |
| GET /api/summary              | —                                                            | 200 {on_hand, overdue, overdue_share, top_books: [{book_id, title, author, loans}]} | 401 |

Поля выдачи в списке: id, issued_on, due_on, returned_on, reader_id,
reader_name, copy_id, inventory_no, book_id, title, author, overdue,
overdue_days, fine.

Правила: экземпляр выдаётся, если он свободен и у читателя нет просроченных
выдач (иначе 409); просрочка — дни от срока возврата до даты возврата (или до
сегодня, если книга на руках); штраф — 10 руб. за день просрочки; повторный
возврат — 409.
